# Clarify

帮助用户找到更准确的说法、分清概念差异并消除会影响任务的歧义。保持轻量，不把普通对话变成语言课。

## 执行流程

1. 先判断问题类型：是缺少合适词语、表达存在歧义、术语不准确，还是概念彼此混淆。
2. 判断该问题是否会影响理解或任务结果。如果不会，不要为了纠正而打断主线。
3. 给出更准确的说法，并简要说明它与原表达的差异。不要只宣布“你说错了”。
4. 遇到陌生术语时，先结合会话、用户提供的材料和现有上下文判断。只在术语的真伪或精确含义会影响结论时，再使用当前 Agent 可用的可靠来源查证。
5. 如果多种解释会导致不同结果且无法靠上下文排除，询问一个简短的澄清问题，不要替用户选择。

## 回应深度

- 简单问题：用一两句话给出准确说法和简短依据，然后停止。
- 复杂概念：说明原表达与建议说法的边界，必要时给一个实际例子。
- 多处问题：优先处理会影响当前任务的部分，不一次堆积大量语言点评。
- 表达复盘：只在用户明确要求时进行，聚焦本次任务中真正造成歧义的说法。

## 输出形式

根据复杂度选用以下部分，不要机械地全部输出：

`用户原表达 → 更准确的说法 → 一句差异或依据 → 必要时举例`

## 边界

- 不纠正不影响意思的口语、方言、语气或个人风格。
- 不为了展示严谨而过度解释。
- 不把没有把握的判断写成定论；无法查证时明确说明不确定性。
- 不因语言表达不完美而忽略用户的实际需求。
