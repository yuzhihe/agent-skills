01 / 产品与商业介绍明亮、秩序感

Stripe

用大段价值陈述和清晰的主次行动，组织多彩的商业首屏。

阅读分析 ↗实测样式 ↗
适合什么时候用

适合商业服务与技术平台介绍。先有明确价值和真实证明，再考虑渐变；不适合把长首屏搬进密集操作页。

02 / 产品与商业介绍暗色、收敛

Linear

以明度、留白和产品细节建立层级，让工作界面本身成为证据。

阅读分析 ↗实测样式 ↗
适合什么时候用

适合有产品可展示的工具型品牌。低对比不等于低可读性，营销预览也不是完整的后台操作规范。

03 / 创作与社区活泼

Gumroad

简短承诺放在中心，装饰留在边缘，行动醒目而明确。

阅读分析 ↗实测样式 ↗
适合什么时候用

适合创作者、数字产品和轻量业务。可替换成自己的插画；粉色硬币和原品牌字标不是可复用素材。

04 / 阅读与文档编辑感、温暖

Works in Progress

以标题、元信息和细线构成阅读秩序，让主稿与其他内容有分别。

阅读分析 ↗实测样式 ↗
适合什么时候用

适合研究笔记、文章合集与专题出版。缺少插画时仍可借鉴编辑层级；移动菜单已观察开合，未做完整可访问性审计。

05 / 作品展示图像优先、克制

Pentagram

让作品决定画面，让导航和说明保持安静。优秀的图片是这个方向的前提。

阅读分析 ↗实测样式 ↗
适合什么时候用

适合设计、摄影、建筑作品集。项目少时可以用静态主图，不必复制自动轮播；图上文字必须检查对比。

06 / 阅读与文档编辑感、清爽

少数派

阅读分析 ↗实测样式 ↗
适合什么时候用

中文文章首页、资讯聚合、专题导读；需要大量表格操作或极少内容的工具页。

07 / 工具与数据实用

GitHub Issues

桌面版有全局导航、局部侧栏、搜索/状态筛选和密集问题行；窄屏收起侧栏，列表成为主轴。

阅读分析 ↗实测样式 ↗
适合什么时候用

工单、问题追踪、审批和运营列表；只需展示品牌故事的营销页。

08 / 商品与商店务实

阅读分析 ↗实测样式 ↗
适合什么时候用

09 / 阅读与文档实用

MDN CSS 文档

阅读分析 ↗实测样式 ↗
适合什么时候用

开发者文档、帮助中心、长篇知识库；短促营销首页或不需要目录的单页介绍。

10 / 产品与商业介绍克制、精致

Apple iPhone

桌面以巨大 “iPhone” 标题和横向机型导航开场，随后进入产品画面；窄屏标题缩小，机型入口可横向浏览。

阅读分析 ↗实测样式 ↗
适合什么时候用

11 / 工具与数据理性

Our World in Data

深蓝站点页眉之下，桌面让主图表与地区选择并列；窄屏把图表放满宽度，地区选择收进按钮。

阅读分析 ↗实测样式 ↗
适合什么时候用

12 / 商品与商店温暖、收敛

Aesop Skin Care

桌面大幅棕米色照片承托标题和说明；手机先呈现影像，再让文字与分类入口独立成块。

阅读分析 ↗实测样式 ↗
适合什么时候用

有高质量影像的护肤、生活方式产品分类；缺少合适影像却只复制米色与留白的电商页。

13 / 搜索与发现务实

阅读分析 ↗实测样式 ↗
适合什么时候用

14 / 创作与社区编辑感

18 / 品牌与议题鲜明
