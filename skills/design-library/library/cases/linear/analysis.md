# Linear · 暗色层次与产品证据

- 来源：https://linear.app/
- 研究日期：2026-10-04
- 范围：主页首屏和嵌入的产品演示片段；桌面 1280×720、窄屏 390×844，页面顶部。
- 适合：开发工具、产品管理工具、以实际工作界面说服用户的产品展示。
- 不适合：把营销首屏直接当后台交互规范；缺乏产品内容却只复制黑底与发光效果。
- 素材依赖：清晰的真实产品截图或可理解的原创产品预览；本研究不包含可复制的产品代码。

## 可观察的设计关系

- 标题近白，说明灰色，背景接近黑色；层级主要来自明度和尺度，品牌色使用很少。
- 导航小而安静，注册按钮浅色填充。产品预览面积大于装饰图形，内容承担说服力。
- 预览中的侧栏、行和属性提供工作场景；这些片段不能证明真实产品全部操作行为。
- 我的判断：留白和产品细节共同制造专注感。只复制留白而没有足够产品信息会显空。

## 响应式与交互

390px 宽时主导航收起，登录/注册仍可见；标题重排为多行，产品演示以缩小且局部裁切的形式出现。不要据此把真实操作界面也整体缩小：营销预览与可操作 UI 的可读性要求不同。

本次没有操作演示内的任务按钮、登录、产品导航，也未测焦点顺序或减少动画设置。初次截取存在入场动画空白，最终截图已重拍为内容可见状态。

## 迁移方法（设计建议）

先准备有意义的产品内容，再定义三层表面：页面底、内容面板、选中/突出状态；用细边框与适量明度差分隔。保持主标题显著，但正文和关键说明不可为“高级感”降到难读。

可用系统字体，并把字重调为接近的 500/600。若做中文工具介绍，降低英文大标题的夸张尺度，避免过多逐字断行。没有产品截图时，用简洁的功能结构示意替代，但不能伪造真实业务数据。

## 限制

研究范围是公开营销页面，不是完整应用、组件库或可访问性审计。边框明度、动态过渡和每种状态未系统采样。
