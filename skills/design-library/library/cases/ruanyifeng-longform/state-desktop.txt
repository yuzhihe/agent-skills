						64 heading 一、Flex 布局是什么？, Value: 2
							65 text 一、Flex 布局是什么？
						66 text Flex 是 Flexible Box 的缩写，意为"弹性布局"，用来为盒状模型提供最大的灵活性。
						67 text 任何一个容器都可以指定为 Flex 布局。
						68 container
							69 text .box { display :  flex ; }
						70 text 行内元素也可以使用 Flex 布局。
						71 container
							72 text .box { display :  inline-flex ; }
						73 container
							74 text Webkit 内核的浏览器，必须加上 -webkit 前缀。
						75 container
							76 text .box { display :  -webkit-flex ; /* Safari */ display :  flex ; }
						77 container
							78 text 注意，设为 Flex 布局以后，子元素的 float 、 clear 和 vertical-align 属性将失效。
						79 heading 二、基本概念, Value: 2
							80 text 二、基本概念
						81 text 采用 Flex 布局的元素，称为 Flex 容器（flex container），简称"容器"。它的所有子元素自动成为容器成员，称为 Flex 项目（flex item），简称"项目"。
						82 container
							83 text 容器默认存在两根轴：水平的主轴（main axis）和垂直的交叉轴（cross axis）。主轴的开始位置（与边框的交叉点）叫做 main start ，结束位置叫做 main end ；交叉轴的开始位置叫做 cross start ，结束位置叫做 cross end 。
						84 container
							85 text 项目默认沿主轴排列。单个项目占据的主轴空间叫做 main size ，占据的交叉轴空间叫做 cross size 。

						241 heading 4.1 order属性, Value: 3
							242 text 4.1 order属性
						243 container
							244 text order 属性定义项目的排列顺序。数值越小，排列越靠前，默认为0。
						245 container
							246 text .item  { order : < integer> ; }
						247 heading 4.2 flex-grow属性, Value: 3
							248 text 4.2 flex-grow属性
						249 container
							250 text flex-grow 属性定义项目的放大比例，默认为 0 ，即如果存在剩余空间，也不放大。
						251 container
							252 text .item  { flex-grow : < number> ; /* default 0 */ }
						253 container
							254 text 如果所有项目的 flex-grow 属性都为1，则它们将等分剩余空间（如果有的话）。如果一个项目的 flex-grow 属性为2，其他项目都为1，则前者占据的剩余空间将比其他项多一倍。
						255 heading 4.3 flex-shrink属性, Value: 3
							256 text 4.3 flex-shrink属性
						257 container
							258 text flex-shrink 属性定义了项目的缩小比例，默认为1，即如果空间不足，该项目将缩小。
						259 container
							260 text .item  { flex-shrink : < number> ; /* default 1 */ }
						261 container
							262 text 如果所有项目的 flex-shrink 属性都为1，当空间不足时，都将等比例缩小。如果一个项目的 flex-shrink 属性为0，其他项目都为1，则空间不足时，前者不缩小。
						263 text 负值对该属性无效。
						264 heading 4.4 flex-basis属性, Value: 3
							265 text 4.4 flex-basis属性
						266 container
							267 text flex-basis 属性定义了在分配多余空间之前，项目占据的主轴空间（main size）。浏览器根据这个属性，计算主轴是否有多余空间。它的默认值为 auto ，即项目的本来大小。
						268 container
							269 text .item  { flex-basis : < length> | auto ; /* default auto */ }
						270 container
							271 text 它可以设为跟 width 或 height 属性一样的值（比如350px），则项目将占据固定空间。
						272 heading 4.5 flex属性, Value: 3
							273 text 4.5 flex属性
						274 container
							275 text flex 属性是 flex-grow ,  flex-shrink  和  flex-basis 的简写，默认值为 0 1 auto 。后两个属性可选。
						276 container
							277 text .item  { flex :  none | [  < 'flex-grow' >  < 'flex-shrink' >? ||  < 'flex-basis' > ]
 }
						278 container
							279 text 该属性有两个快捷值： auto  ( 1 1 auto ) 和 none ( 0 0 auto )。
						280 text 建议优先使用这个属性，而不是单独写三个分离的属性，因为浏览器会推算相关值。
						281 heading 4.6 align-self属性, Value: 3
							282 text 4.6 align-self属性
						283 container
							284 text align-self 属性允许单个项目有与其他项目不一样的对齐方式，可覆盖 align-items 属性。默认值为 auto ，表示继承父元素的 align-items 属性，如果没有父元素，则等同于 stretch 。
						285 container
							286 text .item  { align-self :  auto | flex-start | flex-end | center | baseline | stretch ; }
						287 text 该属性可能取6个值，除了auto，其他都与align-items属性完全一致。
