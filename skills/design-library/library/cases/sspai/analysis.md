# 少数派 · 中文内容站的编辑层级

- 标识：`sspai`
- 来源：https://sspai.com/
- 研究日期：2026-10-05
- 范围：所列页面的局部首屏，桌面 1280×720、窄屏 390×844。
- 适合：中文文章首页、资讯聚合、专题导读。
- 不适合：需要大量表格操作或极少内容的工具页。
- 素材依赖：文章封面和栏目图；无图时仍可保留标题与摘要层级。

## 可观察的设计关系

- 主稿与次稿主要由面积和位置区分，不依赖统一尺寸的卡片墙。
- 白底和较安静的页眉让高密度中文标题成为主要视觉信息。
- 栏目标签、标题和摘要建立由粗到细的阅读路径。

## 响应式与交互

窄屏首屏以单列内容呈现；导航内容明显收束。未测试筛选、搜索、键盘与焦点行为。

## 迁移方法（设计建议）

先定主稿、次稿、常规列表的内容优先级，再用封面比例、标题行数和留白表达层级。中文长标题要实测断行，避免用英文样例推算。

## 避免照搬与已知限制

首页内容随日期更新；文章采样的 14px 是 article 容器计算值，不代表内部每个标题的字号。 本次没有做完整页面、所有断点、键盘可达性或 WCAG 审计；原站可能在研究后变更。截图、商标与作品图仅作研究证据，不作为新站资产。
