# 使用与迁移

这是一个带 50 个本地案例的个人研究用 Skill 包。`SKILL.md` 是入口；案例分析、截图与样式证据全部随文件夹携带。整页布局从 `library/index.md` 进入任务子索引，具体组件或交互查 `library/patterns.md`；按当前需求选择入口，不必同时读取。`library/catalog.html` 可查看所有案例，也可搜索模式名称。正常使用无需访问原站或运行脚本。

## 在 Agent 中使用

把整个 `design-library` 文件夹放入目标 Agent 支持的 Skill 目录，并按该 Agent 的方式刷新/重新发现技能。不要只复制 `SKILL.md`。不同 Agent 的安装位置、启用方式和可用工具可能不同，需要在目标环境确认。

若还没有安装，可在有本地文件读取能力的 Agent 中直接给出这个文件夹内 `SKILL.md` 的路径，请它读取并遵循指引。这是手动使用，不代表自动触发已配置。

示例请求：

- “使用 design-library，给我的中文研究笔记做一个主页。直接从内置库选择参考，不要联网找风格。”
- “使用 design-library，比较适合这个项目的两个已有方向，并继续完成设计。”
- “把这个网站收入 design-library，记录实测和未知项，更新索引。”

## 换设备

直接复制整个文件夹或解压交付的 ZIP。内部路径均为相对路径，不依赖制作电脑的用户名。案例浏览页不使用远程字体、CDN 或网络请求。截图也在包内。

Skill 不提供模型、浏览器或开发运行环境。仅使用文字分析可不依赖浏览器；查看截图需要图像读取能力；研究新网站和验证成品需要相应的浏览器工具。扩库需要目录可写；安装目录不可写时可先在项目中更新完整副本，再按目标环境的安装方式替换。

频繁跨设备更新时，建议维护一个主副本，用已有同步方式或私有版本仓库同步。不要让多个安装副本同时演变成互不一致的主库。此包没有创建云端仓库、自动同步或发布任何内容。

## 范围与来源

当前版本覆盖商业落地页、商品页、创作者社区、中文编辑、技术文档、工单列表、数据图表、内容发现、教育/健康服务和品牌活动，以及定价比较、仪表盘、账户设置、联系表单、预约和登录。第 21–40 个案例中，12 个有设计奖项记录，8 个补充实用界面与中文场景。

0.5.0 又增加 10 个场景案例：订单后台、购物车与结账、分步条件表单、移动议程、深浅主题与按钮状态、中文教程长文、文字型个人网站、机构服务分流、社区主题阅读和富文本编辑器。这批按任务价值收录，不宣称全部获奖。增加五个针对这些缺口的任务入口，仍然先读任务索引，再读少数案例；案例数量增加不会要求一次加载全部分析。详见 [覆盖说明](library/coverage.md)。

案例只记录所见页面和实际操作过的状态，不声称涵盖完整后台、完整交易流程或全站无障碍测试。结账没有提交订单；编辑器没有验证保存/协作；分步表单未完成最终提交。小米、哔哩哔哩的窄屏记录是桌面站裁切观察，Radix 的窄屏组件矩阵也有裁切，均不作为完整移动布局推荐。获奖作品与本次抓取的版本、子页面可能不同；具体奖项与限制见各案例分析。

每份分析带来源与日期，原站以后可能变化。第三方截图只用于个人研究和参考，作品和商标归原权利人；本包不授予将其用于商业产品或公开再分发的权利。制作页面时使用自己的内容和可用素材。

`references/` 是方法；`library/cases/*/meta.json` 是索引与浏览页的维护入口。0.5.1 在这里增加可选的 `patterns` 和 `caveat`，用来引导设计模式检索和提前说明使用边界；旧案例格式仍兼容。扩库时在 Skill 根目录运行 `python3 scripts/build_library.py`，再运行 `python3 scripts/build_library.py --check`；脚本只用 Python 标准库。任务索引、模式入口和浏览页都由它生成，顺序不代表推荐排名。以后库较大时可再分离存储，目前保持整个文件夹即可携带。
